# Как пользоваться DrawingManager

Заказы пишутся **в чате Cursor**, не в меню Aseprite. Агент рисует через мост MCP. Aseprite — живой просмотр. Готовый файл — `.aseprite` в `work/`.

Стиль по умолчанию: **side-on** (вид сбоку), свет сверху-слева. Канон still: [`PIXEL_CRAFT.md`](PIXEL_CRAFT.md). Канон циклов (гибрид до тегов): [`ANIM_CRAFT.md`](ANIM_CRAFT.md). База референсов (текст, не чужие GIF): [`refs/README.md`](refs/README.md). Не копируйте чужие игровые спрайты в `work/`.

---

## Что открыть

| Что | Зачем |
| --- | --- |
| Этот репозиторий в Cursor (`C:\Cursor\DrawingManager`) | Чат и MCP `drawing-manager` |
| Aseprite 1.3+ | Live-просмотр штрихов |
| Чат агента (этот чат) | Единственное место заказа и правок |

Не рисуйте персонажа руками в Aseprite, пока идёт сессия агента: правки заказа — снова в чат («молот ниже», «ок», «перерисуй idle»).

---

## Один раз: подготовка

1. Python 3.10+, Aseprite: `Aseprite/aseprite.exe` (или переменная `ASEPRITE_PATH`).
2. В корне репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python scripts\pack_extension.py
```

3. В Cursor: MCP `drawing-manager` **зелёный** (Settings → MCP). Если серый — Reload Window.
4. Открыть Aseprite → **File → Scripts → DrawingManager: Connect**.
5. Написать в чат: `подключись` или просто вставить форму заказа. Агент проверит `live_connected`.

Без Connect агент не красит в открытом окне.

## Где смотреть результат

| Место | Это |
| --- | --- |
| **Aseprite** (после Connect) | Один документ на файл: правки идут в уже открытую вкладку, без новых окон |
| **`work/…/*.aseprite`** | Исходник, его сдаёте / храните |
| **`work/…/*.json`** рядом | Sidecar: размер, палитра, теги, текстовые ТЗ |
| **`preview/`** | PNG/GIF для чата. Не сдавать как финал |
| Чат Cursor | Превью кадра / анимации, которое присылает агент |

Папки исходников:

- `work/characters/` — существа
- `work/nature/` — дерево, огонь, флаг, вода…
- `work/interiors/` — стол, дверь, факел…
- `work/tilesets/` — тайлы
- `work/locations/` — собранные сцены

Имя файла лучше задать в заказе (`skeleton_64.aseprite`). Если не задали — агент положит осмысленное имя в нужную папку.

## Как писать запросы

Один заказ — **один объект** (скелет, костёр, тайлсет). Локацию заказывайте после пропов и тайлов, или явно: «собери из уже нарисованного».

Обязательно в первом сообщении (или форма ниже):

1. **Тип** — существо / проп / тайлсет / локация.
2. **Размер холста** — персонаж 64–128 (если молчите, будет 96); тайлы только 16, 32 или 64.
3. **Палитра** — бандл `EDG32` (дефолт продукта) / `A64` / `DB32` / …, или `.gpl`, или список hex, или «палитра из `work/….aseprite`».

Без размера и палитры агент **не рисует** — спросит.

Полезное, но не обязательное: вид (если не side-on), направление (`facing` right/left), материалы, акцент (оружие, рога), анимации, референс **описанием** или своим файлом (не чужой коммерческий спрайт в `work/`).

Права в чате коротко: «ок», «капюшон больше», «без walk», «добавь действие slide, 8 кадров».

## Существо: два прохода

Так устроен продукт. Не просите «сразу в цвете», пока не утвердили позу.

```
вы вставляете форму
        ↓
агент создаёт файл + рисует палки и объём (проход 1)
        ↓
вы смотрите Aseprite / превью в чате
        ↓
«ок»  или  правки позы («молот ниже», «нога шире»)
        ↓
агент красит линию / цвет / тень (проход 2)
```

Пока нет «ок» (или явных правок позы), покраски не будет.

Скелет на слое `skeleton` после покраски прячут, **не удаляют**.

## Анимации и описания

Если в заказе ничего не сказано про циклы, существо получит дефолт:

| тег | кадры × мс |
| --- | --- |
| idle | 4 × 200 |
| walk | 8 × 100 |
| run | 8 × 80 |
| attack | 6 × 90 |
| jump | 3 × 80 |
| fall | 3 × 100 |
| hurt | 4 × 100 |
| die | 6 × 120 |

Своё действие: **имя** + **число кадров** + **текстовое ТЗ** одной фразой.

Примеры ТЗ:

- `attack, 10 кадров: замах молотом сверху, без долгого crouch, удар в кадре 2`
- `die, 8 кадров: осыпается в кучу костей, последний кадр — череп и рёбра`
- `idle: дыхание 1px, плащ лагает на кадр`

Текст попадает в sidecar `work/…/имя.json` в поле `tags[].description`. Агент читает его при позе и краске. Локальные рампы — в `local_palettes`. Править описание можно в чате («поправь ТЗ атаки: …») — не обязательно руками в JSON.

Циклы **персонажа** 64–128: гибрид — copy still → части (горб, голова, челюсть, хвост, ноги; копыта стоят) → сдвиг/поворот NN → **кисть на швах** (onion). Copy+сдвиг без кисти сдавать нельзя. Канон: [`ANIM_CRAFT.md`](ANIM_CRAFT.md), [`refs/craft/hybrid-anim.md`](refs/craft/hybrid-anim.md). Ключи — вы пишете «ок», потом краска. Walk не красят без «ок» на ключах. Idle должен качать силуэт (горб/грудь), не только моргать.

Для пропа движение кадра:

- `shift` — дрожь 1–2 px (трава, спокойная вода)
- `copy` — клон кадра и правка
- `redraw` — новый рисунок каждый кадр (огонь, дым)

## Форма заказа (копировать в чат)

Скопируйте блок, заполните, удалите ненужные строки. Пустой шаблон без примеров: [`REQUEST_FORM.md`](REQUEST_FORM.md).

````markdown
```
# DrawingManager — заказ

## Объект
тип: существо | проп | тайлсет | локация
имя файла: work/characters/skeleton_64.aseprite
размер: 64x64
палитра: A64
вид: side-on
facing: right

## Существо (если тип = существо)
сложность: простая | сложная
кто: скелет в плаще с капюшоном
акцент: молот двуручный
материалы: кость, ткань плаща, металл бойка
поза (проход 1): стоит, молот поднят вверх, плащ назад
анимации: только still, 1 кадр
# или дефолт 8 циклов, или список:
# idle: 4 кадра, дыхание 1px, лицо лагает
# walk: 8 кадров
# своё: slide, 8 кадров, подкат по земле + пыль

## Проп (если тип = проп)
вид: fire | torch | flag | tree | bush | grass | water | rock | cloud | smoke
      | wall | floor | door | window | table | chair | chest | bed | banner
размер: 32x48
кадры: 6
движение: redraw | shift | copy
папка: work/nature/ | work/interiors/

## Тайлсет (если тип = тайлсет)
tile_size: 16 | 32 | 64
тема: meadow | dirt | water | dungeon | interior_wood
автотайл: да

## Локация (если тип = локация)
размер: кратно тайлу, например 256x144
тема: meadow | interior_wood | dungeon
из чего собрать: work/tilesets/… , work/nature/… , work/characters/…

## Не делать
не копировать чужие спрайты
не top-down (если не просили)
```
````

Минимальный заказ, которого достаточно:

```
существо, 64x64, палитра A64, side-on.
скелет в плаще, молот вверх. без анимации, один кадр.
```

## Короткие команды в чате

| Вы пишете | Что происходит |
| --- | --- |
| форма / бриф выше | Новый файл, проход 1 (существо) или сразу проп/тайлы |
| `ок` | Проход 2, покраска |
| `молот ниже, капюшон шире` | Правка позы, снова ждёт «ок» |
| `добавь attack, 10 кадров: …` | Новый тег + ТЗ |
| `перекрась плащ в синий` | Правка цвета после покраски |
| `покажи анимацию walk` | Превью в чат (GIF может кратко уйти в headless) |
| `сохрани` | `save_sprite` в тот же путь в `work/` |

## Частые ошибки

- Заказ в Aseprite, а не в чате — агент его не увидит.
- Нет Connect — нет live.
- «Сразу цвет» до «ок» — поза ещё не утверждена.
- PNG из `preview/` как сдача — нужен `.aseprite` в `work/`.
- Референс = вставить спрайт из чужой игры в `work/` — нельзя. Опишите или приложите **свой** файл.
