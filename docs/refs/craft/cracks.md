# Трещины и сколы

Когда: wear после shade. SLYNYRD 2, PIXEL_CRAFT.

- Трещина — **вырез** в кластере (2–8 px, 1–2 тона темнее), не сетка линий поверх.
- На роге/копыте: скол на свету = потерянный кусок + тёмное дно; на тени — только тёмный зазор.
- Редкость: 1–3 скола на акцент (горб, копыто), иначе шум.
- Не обводить трещину вторым контуром.

## Для DM

- Слой `shade` или дырка в `color`. Пыль в складке — один короткий кластер (`#8b9bb4` / холод бандла).
