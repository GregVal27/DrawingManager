# Глаза и пасть (96)

Когда: эмоции still/idle. Pixnote character-size sense + SLYNYRD 29 метод (без anime-дефолта). Derek Yu: лицо читается пятном.

- Глаз: **2×2** полость + **1px** блик (тёплый) + **1px** веко (меняется в idle).
- Не 4px kawaii. Side-on: глазница под надбровным валиком.
- Пасть: закрыта / оскал (зубы 1–3 px) / удар (полость больше, spec). Состояния — разные кластеры, не shift челюсти как cel.
- Внутренний контур лица почти не нужен, если пятна скулы и морды уже контрастны.
