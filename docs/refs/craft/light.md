# Словарь света

Когда: pass 2 form light; персонаж 96+. Источники: SLYNYRD 6, Pixnote shading, PIXEL_CRAFT.

| термин | что это на спрайте |
| --- | --- |
| **key** | Главный свет верх-лево. Самая большая светлая зона материала. |
| **highlight** | Узкая тёплая ступень на обращённой к ключу грани. |
| **terminator** | Перелом объёма (клин/ступень), не концентрический пояс. |
| **bounce** | Холодный или розовый отсвет снизу/от соседней массы (1 кластер). Ambient bounce, не rim по всему силуэту. |
| **occluded far-limb** | Дальняя рука/нога на ступень темнее и короче. |
| **wet spec** | 1–2 px на `fx`: пасть, мокрый кератин. Не едущая полоса, если угол не меняется. |
| **rim** | Только по заказу (контровый свет). По умолчанию выкл. |

## Для DM

- Шкура: мягкий terminator. Рог: жёсткие грани. Копыто: скол + грязь. Пасть: spec.
- Proof: сфера 32px теми же hex, что горб; если сфера плоская — рампы мало.
- Banding (saint11 article 5): не кольца тени; AA на 64 выкл. по умолчанию.
