# Контуры (Lospec / Pixnote)

- Lospec outlines: https://lospec.com/articles/pixel-art-outlines/
- Pixnote sel-out: https://pixnote.net/en/learn/outlines/

Сверка с PIXEL_CRAFT:

| приём | в DM |
| --- | --- |
| Outer black wrap | Запрещён как финал (`outline_from_volume`) |
| Inner outline | Только стык без контраста, короткая, **светлее внешнего** sel-out |
| Selective outline / sel-out | Канон: свет снимает линию |
| No outline | Ок на 16–32 и на пятнах, которые уже читаются (Derek Yu / Cave Story) |
| Colored outline | Тонированный материал, не чистый `#000` кроме UI |
| Rim light | Только по заказу |

Ambient bounce закрывает «дырку» плоского низа лучше, чем второй контур вокруг ног.

## Для DM

- Не обводить подошвы и хват. AA не на 45° и не в прозрачность.
