# Читаемость ×1 (Derek Yu / Cave Story)

- Tutorial: https://www.derekyu.com/makegames/pixelart.html
- Разбор оси: [`sideon.md`](../sideon.md)

На мелком спрайте форма живёт **пятном и щелью**, не клеткой внутреннего контура. На 96 всё ещё «рисуешь», но:

- Чеклист ×1: роль + **4–6 подформ**, не 2 кляксы.
- Мало внутренних линий: если морда/горб/копыто читаются кластером — линию стереть.
- Оружие/рога — выступ силуэта со щелью, не приклеенный квадрат.

Cluster sketching (saint11): читать пятнами до пиксель-ханта.
