# Smear

Когда: быстрая дуга attack/run. SLYNYRD 9, saint11 MotionBlur, [`ANIM_CRAFT.md`](../../ANIM_CRAFT.md).

- Один кадр **цвета дуги**, не промежуточная конечность в середине пути.
- Форма smear продолжает силуэт стойки → контакта.
- 1–2 тона материала + опционально светлее на носу дуги.
- После smear — hold удара, не сразу idle.

## Для DM

- Слой `fx`. `clear_cel` на этом кадре, нарисовать дугу. Не `shift_cel` руки.
