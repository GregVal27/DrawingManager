# Сводка обучения (saint11 → агент)

Выжимка после разбора GIF. Полные карточки в [`cards/`](cards/). Канон не дублировать: [`PIXEL_CRAFT.md`](../../PIXEL_CRAFT.md).

## Уже совпадает с PIXEL_CRAFT

Кластеры, сироты, 1px линия, диагональный стык, sel-out, hue-shift, силуэт первым, свет верх-лево, запрет pillow и doubles.

## Что saint11 добавляет (использовать)

1. **Alignment / banding** — внутренние лестницы не копируют внешний край; сдвиг 1px.
2. **Band compression** — пояса цвета уже, ступени не кольцами.
3. **Грани** — сплошной тон на плоскость, не мягкий градиент по всему кирпичу.
4. **Словарь света** — terminator, bounce, hard projected vs soft self-shadow.
5. **Контур экономит пиксели** — на 64 иногда лучше щель цветом, чем линия.
6. **Внутренний контур светлее** внешнего.
7. **Острый угол** — намеренный corner-pixel, не ошибка.
8. **Пайплайн** — volume → silhouette → flats → shade → акцент; не линия вокруг пустоты.
9. **Анимация** — still → rough timing → keys → in-betweens; smear ок; не ломать кластеры между кадрами.
10. **Модуль** — для боссов/машин сдвиг слоёв; на мелком 64 чаще целиком перерисовать.
11. **1-bit** — только по заказу; идея «одна черта силуэта» полезна всегда.
12. **Walk** — contact / down / passing / up; руки против ног; дальняя конечность темнее.
13. **Run** — 4 ключа × 2 ноги; обязательна фаза обе ноги в воздухе.
14. **Jump** — invert на пике; squash на контакте; anticipation у игрока короткий.
15. **Idle** — 1px down/up; лицо лагает за силуэтом; не только вертикаль; blink/yawn редко.
16. **Attack игрока** — без замаха; первый кадр уже удар + overshoot корпуса; recover длиннее.
17. **Hurt/die** — 1 кадр extreme, медленный recover; die обрывает recover; мелкий моб: чёрный кадр перед взрывом.
18. **Defend** — попал, но цел: вспышка + shine, без шрапнели.
19. **Металл** — холодный жёсткий блик, тёплая щель, полоски отражения, не squash.
20. **Дерево** — фаски до текстуры; кора чешуйками одним пятном света; матовый, редкий блик.
21. **Ткань** — синус ветра; складки из точек сжатия; почти без specular.
22. **Лёд** — снег на горизонталях; трещины + glow; сосульки стекают вертикально.
23. **Камень** — три породы (слои / плоскости / поры), не один шум.
24. **Череп** — приоритет глазница → maxilla → скула; кости лентой; суставы undead лагают.
25. **Огонь** — волны от яркого низа, луп, частицы вверх; не эллипс.
26. **Дым** — одна частица целиком, потом следующая; contrast-кадр; не ломать форму рано.
27. **Взрыв** — FLASH → BLAST → FIRE → SMOKE; огонь быстро, дым медленно; blast без шума.
28. **Молния** — быстро, blank-кадры, другой силуэт на ярком кадре.
29. **Вода** — 2 слоя, рябь ≤1px, пена как частицы.
30. **Тайлы** — master со сдвигом 50%; вариации только в центре.
31. **Облака** — сферы с плоским низом, низкий контраст, даль выцветает.
32. **Крона** — силуэт → объём-сфера → деталь по краю, внутри чисто.
33. **Easing** — расстояние между рисунками = ускорение; linear скучно; attack = back/overshoot, средний кадр можно выкинуть.
34. **Squash** — масса константа; prepare против действия; металл/кость почти не деформировать.
35. **Subpixel** — часть раньше целого; двигать свет и точки излома, не форму.
36. **Loop** — разные длины подциклов, не все с кадра 1; частицы в разных фазах жизни.
37. **Smear** — соединяет с прошлым кадром; светлые текут по тёмным.
38. **Четвероногие** — два бипеда со сдвигом; голова лагает за передними ногами.
39. **3-point свет** — key/fill/rim; дефолт DM остаётся один key верх-лево.
40. **Кровь/слизь** — держать связь кластеров; слизь не любит острые углы и ранний распад.
41. **Тёмная vs светлая магия** — снизу/хаос/шипы vs сверху/порядок/круги, без дыма у holy.
42. **Пули** — тёплое ядро; flash старта и конца важнее самой пули.
43. **Импакт** — цель bounce; выкинуть средние кадры; freeze максимум 1 кадр.
44. **Ломание** — одна узнаваемая исходная форма среди осколков.
45. **Top-down / iso / 9-slice** — только по заказу; стек головы; Y-sort в движке, не в Aseprite.
46. **Корабль / пушка / меч** — силуэт и функция (дуло/хват) раньше greeble; пилу не вращать.
47. **Ловушка** — tell до удара, ритм, который учат.
48. **Параллакс** — даль холоднее, тусклее, меньше деталей; небо 2 цвета.
49. **Resize** — перерисовать, не scale; на меньшем холсте выкидывать детали (часто лицо).
50. **Тьма** — слить с фоном; кластер только если нужен; rim вместо полной раскраски.
51. **Руина** — силуэт сломан, история поломки, разные стадии одного объекта.
52. **Cute** — только по брифу: глаза ниже, мешок муки, всё мнётся.

## Чего не тащить в дефолт DM

- Top-down / isometric / 9-slice UI как основной вид.
- Полный dither как стиль затенения (исключение: мох, крупный песок, клавиатура в интерьере — локально).
- Копирование демо-спрайтов с GIF в `work/`.
- Вращение кусков мелкого персонажа и пил (ломает пиксели) — smear вместо rotate.
- Длинный anticipation у игрока (jump / attack / wall-kick).
- Автомасштаб готового `.aseprite`.
- Chibi-пропорции без заказа.
