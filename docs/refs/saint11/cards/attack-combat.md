# Атака, защита, смерть (пачка B)

Адаптация saint11, CC BY 4.0. Вид — **side-on**. Дефолтные теги DM: `attack`, `hurt`, `die`.

---

## AttackSheet

- URL: https://saint11.art/img/pixel-tutorials/AttackSheet.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#AttackSheet
- Когда: тег `attack` (удар, взмах, выстрел).

### Steps

- Суть — **тайминг**, не число пикселей на клинке.
- Типичная нарезка: **3 кадра удара + ~4 кадра возврата** в idle (дефолт DM attack = 6 — укоротить recover или уплотнить удар).
- Для **игрока: без кадра anticipation**, иначе input lag. NPC можно замах.
- Первый рабочий кадр после idle — уже удар. Тело **уходит дальше idle** (bounce / overshoot по X).
- Smear / белый swoosh показывает дугу и hitbox.
- Та же схема: рубящий вниз, снаряд с flash дула.

### Don'ts

- Замах в 2–3 кадра у игрока перед попаданием.
- Удар на месте без смещения корпуса.

### Для DM

- Дефолт 6 кадров: strike (smear), follow-through, recover×3, settle. Swoosh на `fx`. Не копировать демо-человечка с GIF.

## Defend

- URL: https://saint11.art/img/pixel-tutorials/Defend.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Defend
- Когда: блок щитом, броня «держит», неуязвимость.

### Steps

- Показать: удар **попал**, урона нет.
- Снаряд: касание → короткая вспышка → отскок/падение; щит чуть дёргается; затем **shine** по щиту. Реагирует только защищённая зона.
- Броня: маленький сдвиг силуэта, **длинный recover**, блик «после удара» = «цела». Не ломать контур.
- Soft-hit FX: короткие **круги**, без осколков и искр (искры = «сломалось»).
- Думать звук (clink vs thud) — анимация к нему.

### Don'ts

- Сильный squash всего тела на блоке.
- Шрапнель на «успешной» защите.

### Для DM

- Кастом `add_action("defend", …)` или короткий `hurt` без смещения. Вспышка и shine на `fx` (1–2 кадра). `shift_cel` щита 1px.

## Death

- URL: https://saint11.art/img/pixel-tutorials/Death.GIF
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Death
- Когда: теги `hurt` / `die`.

### Steps

- **Hurt:** один кадр максимального отлёта (overshoot), дальше **медленный** recover в idle. Импакт = 1 кадр, не 3 одинаковых.
- Squash при ударе с **сохранением массы** (короче → шире). Compress размера — осторожно, чтобы оставалось правдоподобно.
- **Die:** тот же сильный первый кадр; recover обрывается («сдался»): колени, руки и голова **лагают**. Падение: руки почти до земли, **overshoot пола на 1px**, затем rest с лёгким отскоком рук.
- Мелкий враг: **чёрный кадр** перед взрывом для контраста. Сам взрыв — карточка Explosion.

### Don'ts

- Hurt из нескольких одинаковых «трясок» без easing.
- Die без сильного первого кадра (слабо читается).

### Для DM

- Дефолт hurt 4 / die 6: кадр 1 = extreme; остальные recover или collapse. Кровь/пыль на `fx`, гаснут на recover. Чёрный кадр — только мелкий проп/моб, не герой 64.
