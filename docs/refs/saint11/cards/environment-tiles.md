## Tiles

- URL: https://saint11.art/img/pixel-tutorials/Tiles.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Tiles
- Когда: `create_tileset`, швы.

### Steps

1. **Master tile:** полный тайл, стыкуется по 4 краям. Черновик → сдвиг 50% → починить центр → сдвиг снова.
2. Основные края: top / mid / bot (верх светлее/площе, низ темнее/зуб).
3. Остальные формы зависят от движка (трубы, колонны) — у DM blob-автотайл 16 плиток.
4. Вариации: менять **только центр**, края те же, иначе сетка видна.

### Don'ts

- Уникальный край на каждом варианте (поедут швы).
- Один и тот же центр на всю карту без вариации mid/top.

### Для DM

- `preview_tileset_seams`. `paint_autotile` края 2–5 = top/side; fill = master. Вариацию класть в центр тайла 1 и 14, не в кромку.

## Clouds

- URL: https://saint11.art/img/pixel-tutorials/CLouds.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Clouds
- Когда: небо локации, проп cloud.

### Steps

- Группы сфер с **плоским низом** → свет на сферах → мало кластеров → плоская база → hue-shift тени → **низкий контраст**.
- Солнце сзади → яркий обод. Тень обычно в плоской нижней зоне.
- Дальние облака выцветены; ближние контрастнее. Рисовать сзади вперёд. Типов много — смотреть реф.

### Don'ts

- Жёсткий металл-контраст на пушистом облаке.
- Куча мелких кластеров «ваты».

### Для DM

- Слой `sky` локации или `create_prop(..., kind="cloud")` + `shift`. Rim при контровом свете на `fx`, не чёрный outline.

## Vegetation

- URL: https://saint11.art/img/pixel-tutorials/Vegetation.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Vegetation
- Когда: дерево/куст как проп (вид гайда ближе к RPG-кроне; принципы кроны те же).

### Steps

- **Shape** (силуэт читается деревом без цвета) → **Light** (объём как сфера, мало цветов) → **Detail** (края подробные, **внутри чисто**).
- Тёплый свет (желтоватый), холодная тень. Половина рампа — светлая зелень; зоны отдыха глазу.
- Слои листвы, repeating leaf-pattern против шума. Без сирот.
- Листья падают синусом и крутятся. Лианы к воде — плюс.

### Don'ts

- Шум внутри кроны.
- Начинать с отдельных листьев.

### Для DM

- `create_prop(..., kind="tree"|"bush")`. Крона = кластеры, не сетка листьев. Side-on ствол виден сбоку — не копировать top-down крону 1:1.

## Vegetation2

- URL: https://saint11.art/img/pixel-tutorials/Vegetation2.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Vegetation2
- Когда: травка у платформы, слой перед игроком, ветка.

### Steps

- Слои тайла: highlight / base / shadow / dirt. Мало цветов, без сирот и шума.
- Деталь **перед** игроком даёт глубину. Думать 3D на кромке платформы. Лианы ниже collision.
- Разные глубины и паттерны против монотонности; пустые зоны дают фокус. Не переигрывать деталь.
- Каждый листочек сознательный, не случайные точки. Края контрастнее. Дерево: почти параллельные бороздки. Тонкие «нитки» только тенью и не в низком контрасте.

### Don'ts

- Случайные точки «травы» по всему тайлу.
- Деталить и центр, и край одинаково.

### Для DM

- Трава: `kind="grass"`, motion `shift`. Передний куст — слой `nature` поверх персонажа только если сборка локации это предусматривает.

## Vegetation3

- URL: https://saint11.art/img/pixel-tutorials/Vegetation3.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Vegetation3
- Когда: пальма, тропики, мох, крупные листья.

### Steps

- Рефы с фото: арки слизи/мха, дырки в арках, грибок на дереве, связать арки мелкими лианами, big/small вариации паттерна, лианы для силуэта, fade дали в цвет неба.
- Крупный лист: контур по 3D-складке, светлая/тёмная сторона, слои света, specular по кромке.
- Ствол: свет/тень → трещины и шишки по одной → точки света → backlight другого цвета. Один цвет за проход.
- Мох/куст: база → светлые комья → плотная тень → дробить комья → глубина → specular → крошечные былинки.
- Dither ок **как мох**, не как shading всего спрайта. Спирали как текстура.

### Don'ts

- Копировать пальму с GIF в `work/`.
- Полный dither кроны.

### Для DM

- Tropic tree = инвентарь форм (ствол / лист / лиана / мох), затем PIXEL_CRAFT pass 2. Dither мха локально.

## Parallax

- URL: https://saint11.art/img/pixel-tutorials/Parallax.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Parallax
- Когда: слои локации, глубина фона.

### Steps

- `render = (pos - camera) * scroll_factor + offset`. Ближе → быстрее.
- Близко: высокая насыщенность, контраст, яркость, тёплый hue, много деталей. Даль: наоборот, выцветает в цвет неба.
- Foreground: `scroll_factor > 1`. UI: factor 0 + offset. Factor почти всегда > 0.

### Don'ts

- Дальний фон той же насыщенности, что передний куст.
- Крутить камеру в Aseprite — это правило движка.

### Для DM

- Слои локации: `sky` (даль) → `ground` → `nature` → `furniture` → `characters`. Дальше меньше цветов и контраста.

## City

- URL: https://saint11.art/img/pixel-tutorials/City.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#City
- Когда: side-on улица, не top-down дома.

### Steps

- Кирпичи-массы → свет → эрозия и трещины → глубже швы в местах → снизить контраст детали светлым тоном.
- Небо: 2 цвета, низкая насыщенность и контраст. Даль: 3 цвета. Перед: мало цветов, но ярче.
- Свет → блок конструкций → текстуры → растительность / грязь / дождь / снег.

### Don'ts

- Равномерная сетка кирпича без эрозии.
- Небо из полного A64.

### Для DM

- Локация, не персонаж. Свет один (верх-лево). Мелкая анимация (листок) — `shift` 1px.

## indoors

- URL: https://saint11.art/img/pixel-tutorials/indoors.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#indoors
- Когда: комната, мебель (`work/interiors/`).

### Steps

- Block → simple light → carve details → smaller props.
- Комплементарная пара; стены без скачков hue, но с мелкой вариацией; низкая насыщенность и температура.
- Передняя мебель: выше насыщенность и контраст. Постеры — мало цветов и контраста. Цоколь. Клавиатура — короткий dither.
- Длинные медленные лупы (аквариум); лампа — едва заметный flicker.

### Don'ts

- Радужные стены.
- Крупная мебель как «готовый пиксель», если заказ был только volume-блок-аут.

### Для DM

- `create_prop` стол/стул/дверь. Крупная мебель может остановиться на `volume` (PLAN). Живые лупы на `fx`.

## Ruins

- URL: https://saint11.art/img/pixel-tutorials/Ruins.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Ruins
- Когда: разрушенное, dungeon, старый проп.

### Steps

- Руина **рассказывает**, почему сломано. Свежее: огонь/дым. Старое: растения, низкий контраст, круглые края.
- Силуэт тоже «сломан». Сломать симметрию, неровные плоскости, повторить объект в разных стадиях разрушения. Провода/лианы.
- Паутина не яркая. Царапины: паттерн толще в середине. Трещины — не ёлка. Выбоины шумные и мелкие. Дыра: показать фон и внутренность.

### Don'ts

- Идеально симметричная «сломанная» колонна.
- Яркая белая паутина.

### Для DM

- Инвентарь: скол, лиана, дыра с внутренностью. Дым — SmokeSheet. Glitch-экраны — карточка Glitch.

## Stars

- URL: https://saint11.art/img/pixel-tutorials/Stars.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Stars
- Когда: ночное небо, космос, слой `sky`.

### Steps

- Обычные звёзды: 1px или 2×2; реже крест. Фон: 2–3 тёмных оттенка. Мерцание: мало кадров, не все, **не в фазе**.
- Крупная: hue-shift и насыщенность к центру; редкие яркие точки задают ритм.
- Планета: два круга = серп тени; rim на тёмной стороне; спирали поверхности. Дальние планеты без контраста.
- Туманность: спирали-щупальца, край растворяется в звёздах.
- Фон **не `#000`**.

### Don'ts

- Чисто чёрный космос.
- Все звёзды мигают вместе.

### Для DM

- `sky` локации. Мерцание: `shift`/перекрас 1px на `fx`, фазы сдвинуты (карточка loop).
