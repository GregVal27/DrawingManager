## Fundamentals

- URL: https://saint11.art/img/pixel-tutorials/Fundamentals.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Fundamentals
- Когда: любой персонаж/проп до покраски и при polish.

### Steps

- Цель: читаемость вверх, шум вниз.
- Держать **мало крупных кластеров** одного цвета, а не россыпь мелких.
- Диагонально касающиеся пиксели «слабо связаны» — не считать их одним кластером.
- **Orphan** (пиксель не в куске) почти всегда шум. Исключение: 1–2 сильных акцента (блик в глазу, искра).
- В анимации **не ломать кластеры**: пятно цвета едет целиком, не рассыпается.
- Dither по умолчанию не использовать; только как текстура металла/ткани, коротко.
- Повторяющийся узор читается лучше хаоса.
- Простые узнаваемые формы (`O`, `+`, клин) чище сложных клякс.

### Don'ts

- Шахматный dither «для сглаживания» по всему спрайту.
- Россыпь одиночных пикселей «для детализации».

### Для DM

- Кластер = заливка на `color`, не сетка `draw_rect` 2px.
- Сироты ловит `scripts/pixel_qa.py`.
- Анимация: `copy_cels` / `shift` сохраняет кластер; `redraw` — заново собрать пятно.

## Fundamentals2

- URL: https://saint11.art/img/pixel-tutorials/Fundamentals2.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Fundamentals2
- Когда: чистка контура и кривых.

### Steps

- Прямая: все ступени **одинаковой длины** (1-1-1 или 2-2-2).
- Если угол «неидеальный»: повторять соседние длины, напр. `2,2,3,2,2,3`.
- Кривая: ступени **убывают к углу**, потом снова растут (4→2→1→1→2→4). Не 4→1→3.
- Сегменты линии стыкуются **по диагонали**. Ребро-к-ребру в углу = толстая точка (**double / bad corner**).
- Квадраты 2×2 вложенного цвета выглядят кирпичом. Класть тон **кирпичной кладкой** (со сдвигом), искать «воображаемые квадраты».

### Don'ts

- Грязная линия с L-уголками.
- 2px толщина «на всякий случай».

### Для DM

- Использовать `DM.draw_line_px`, не Bresenham `DM.draw_line`.
- После наброска: пройти контур, снять corner-doubles.

## Alignment

- URL: https://saint11.art/img/pixel-tutorials/Alignment.png
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Alignment
- Когда: banding, «лесенка» внутри объёма совпадает с внешним краем.

### Steps

- Текст гайда: *Breaking the alignment makes the most of the resolution and makes shapes look smoother.*
- Внутренние границы (блик/тень) **не копировать ту же лестницу**, что у внешнего контура. Сдвинуть на 1px.
- Так кривая использует сетку дважды и кажется глаже.

### Don'ts

- Концентрические кольца тени, параллельные силуэту (banding / pillow).

### Для DM

- Shade не «обвести volume минус 1px». Кластер тени своей формой, ступени другие.

## Silhouette (Character Design 1)

- URL: https://saint11.art/img/pixel-tutorials/Silhouette.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Silhouette
- Когда: pass 1 и silhouette lock pass 2.

### Steps

- Силуэт — «пролог»: роль читается без цвета (меч, броня, щупальца, гусеницы).
- Широкие плечи = сила; острые длинные конечности = опасность.
- В силуэт заложить **один сильный элемент** (оружие, капюшон, молот).
- Процесс saint11: **silhouette sketch → details → animate**.
- Анимацию можно набросать чёрными пятнами: действие должно читаться в чёрном.

### Don'ts

- Стойка «палка с руками по швам» без щелей.
- Добавлять детали, которые ломают уже работающий чёрный тест.

### Для DM

- Совпадает с чёрным тестом PIXEL_CRAFT и слоем `volume`.
- Side-on: щель плащ/спина, оружие/голова, между ног.

## Pipeline (Pixel Art Process)

- URL: https://saint11.art/img/pixel-tutorials/Pipeline.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Pipeline
- Когда: любой новый спрайт, не «с контура».

### Steps

1. Примитивы объёма (массы).
2. Силуэт поверх.
3. Плоские цвета (flats).
4. Свет (верх-лево): тень снизу, блик сверху.
5. Полировка: кромки, один акцент (глаз/линза).

### Don'ts

- Рисовать сразу попиксельную линию вокруг пустоты.

### Для DM

- `volume` = шаг 1–2; `color` = flats; `shade`/`fx` = 4–5. Не `outline_from_volume` как финал.

## Planning (Animation Planning)

- URL: https://saint11.art/img/pixel-tutorials/Planning.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Planning
- Когда: теги walk/run/attack с несколькими кадрами.

### Steps

1. Still: знать, кого анимируем (часто idle 1).
2. Грубый прогон тайминга, без пиксель-ханта.
3. **Keyframes** — позы, без которых действие не читается.
4. **In-betweens** — заполнить дыры; copy-paste; подкрутить длительность. Странный промежуточный кадр (smear) допустим.
5. В черновике разные цвета = разная глубина (перед/зад).
6. Отдельные файлы/теги на цикл, потом сборка.

### Don'ts

- Дорисовывать все кадры до готовых ключей.

### Для DM

- Теги = ключи. `copy_cels` / `shift_cel` = in-between. Sidecar хранит ТЗ позы.

## Modular

- URL: https://saint11.art/img/pixel-tutorials/Modular.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Modular
- Когда: большой босс, механизмы; не мелкий 64 если можно нарисовать целиком.

### Steps

- Скетч целиком → части по отдельности (включая скрытые за другими).
- Крупное: scale/rotate кусков. Мелкое: модуль слабее полезен.
- Стык сустава прятать под пластину / другой материал.
- Машины: несколько слоёв, сдвиг на 1–2px, **без** вращения (ломает пиксели).
- Часть вещей всё равно frame-by-frame (ткань, огонь).

### Don'ts

- Вращать мелкий 64-персонаж кусками вместо отрисовки позы.

### Для DM

- Complex groups `sk_*` / `vol_*` = модуль для позы, не замена paint.
- Пропы `shift` / `copy` ≈ модульный сдвиг.

## 1-bit

- URL: https://saint11.art/img/pixel-tutorials/1-bit.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#1-bit
- Когда: пользователь просит 1-bit / Game Boy; иначе — только идея «одна главная черта».

### Steps

- Мягкая тень в 1-bit = **dither**, не перебор.
- Мало деталей: линии больших форм + немного сплошных теневых блоков.
- Следить за одиночными пикселями на линиях.
- Контур белый или чёрный; иногда двойная линия для контраста.
- Иконка: одна узнаваемая черта; не вышло — стереть и снова.

### Don'ts

- Переносить 1-bit dither в цветной EDG32/A64 спрайт по умолчанию.

### Для DM

- Не дефолт. Полезно как упражнение силуэта.
