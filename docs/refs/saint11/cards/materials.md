## Metal

- URL: https://saint11.art/img/pixel-tutorials/Metal.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Metal
- Когда: броня, клинок, молот, шлем.

### Steps

- Порядок: форма → базовый свет → базовая тень → backlight + **жёсткий specular** → намёк отражения среды.
- У saint11 на металле: свет **холоднее и менее насыщен**, тень **теплее и насыщеннее** (обратить внимание: это может расходиться с общим «тень в холод» PIXEL_CRAFT — для металла следовать этой карточке: холодный блик, тёплая щель).
- Рамп металла: резкий скачок к почти-белому; пластик — мягкий.
- Сильный backlight. Царапины = история. Глянец по износу.
- Простые отражения: несколько **вертикальных** полос свет/тень на клинке.
- Металл **жёсткий**, не тянется; двигаются отдельные пластины.
- Блик анимировать при смене угла.

### Don'ts

- Мягкий градиент как у кожи.
- Тянуть броню squash как плоть.

### Для DM

- 3 тона + 1 пиксель specular на `fx`. Молот: кромка тёмная, блик 1–2 px сверху-слева, полоска на бойке.

## Wood

- URL: https://saint11.art/img/pixel-tutorials/Wood.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Wood
- Когда: пень, доски, древко, мебель.

### Steps

- Силуэт средним тоном и простыми массами → тени **без pillow** → кольца пня (деталь гаснет вдаль) → кора как **чешуйки**, свет и локально, и как одно пятно → трещины/трава в конце.
- Доски: сначала **большие фаски и стыки**, текстура после. Контраст на пересечениях.
- Словарь: сучки, гвозди, трещины, кора, мох.
- Hue-shift тени; блик редкий (дерево матовое); переходы медленные.

### Don'ts

- Pillow на торце пня.
- Текстура коры до объёма.

### Для DM

- 3 тона дерева + 1 мох. Кольца — короткие дуги, не полный концентрический комикс. Древко молота: 2 фаски, не штриховка.

## Fabric

- URL: https://saint11.art/img/pixel-tutorials/Fabric.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Fabric
- Когда: плащ, флаг, баннер, капюшон.

### Steps

- Ветер = **синус** по полотну; сдвиг волны по направлению ветра. Свет и тень уезжают **от** источника ветра.
- Мягкие тени, **почти без бликов**. Тёмные зоны без мелкой складки.
- Складки: параллельны там, где натяжение; перпендикулярны там, где слабо; веером из точки сжатия. Складка кидает тень на соседнюю ткань.
- Двигать ткань, **анатомию под ней не ломать**. Мало складок.

### Don'ts

- Сетка складок по всему плащу.
- Яркий specular как у металла.

### Для DM

- Плащ: 2–3 вертикальные складки (PIXEL_CRAFT). Флаг/баннер: `create_prop` motion `redraw` или `shift` 1px по синусу. Свет верх-лево + тень складки.

## Ice

- URL: https://saint11.art/img/pixel-tutorials/Ice.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Ice
- Когда: лёд, сосульки, снег на крыше.

### Steps

- Рамп: snow light → snow shadow → ice glow → ice base → ice shadow → ice deep.
- Снег лежит на **горизонталях**. Край снега — рваный зигзаг + редкие «вверх» хлопья.
- Шар/глыба: форма → отражение-тень → зона блика → трещины и яркие щели → снег сверху → backlight.
- Сосульки: капли дают шипы и сверху, и на земле; свет и тень **стекают** друг в друга вертикально.
- Отражения циклируются по плоскостям льда.

### Don'ts

- Снег на вертикальной стене как шапка.
- Лёд = белый градиент без трещин и glow.

### Для DM

- Glow/трещина на `fx` (1px cyan). Снег — светлый кластер сверху объёма, не обводка.

## Rock

- URL: https://saint11.art/img/pixel-tutorials/Rock.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Rock
- Когда: камень, утёс, dungeon-тайл.

### Steps

- **Осадочная:** слои, мягкая, крошится, большие мягкие блики. Мало шума и сирот, мало цветов в детали.
- **Метаморфическая:** из осадочной/изверженной; сильные блики; крупные сколы; чистые плоскости. Пайплайн: силуэт → база тени → мягкие слои → блик → backlight + убрать шум → крошка.
- **Изверженная:** лава; округлые массы; пузыри = дыры и острия; пористая → **очень мягкий** блик.

### Don'ts

- Один шум dither на все три типа.
- Сироты «для фактуры» на осадочной.

### Для DM

- `create_prop(..., kind="rock")`: выбрать один тип. Dungeon-тайл ближе к метаморфической (плоскости + backlight).

## Sand

- URL: https://saint11.art/img/pixel-tutorials/Sand.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Sand
- Когда: дюны, берег, пустынный пол.

### Steps

- Свет тёплый, тень **холоднее**. Направление ветра задаёт асимметрию дюны.
- Рябь: жёсткий край волны → мягкая тень у низа холма → крупные холмы к краю тайла, мелкая рябь вокруг.
- Дюна: форма → тёплый свет наветренной стороны → rim на гребне → жёсткая тень с подветра → мелкие бугорки силуэта.
- Пейзаж: S-кривые гребней, даль меньше деталей. Крупный план — грубый, чуть sparkle (короткий dither).

### Don'ts

- Прямые гребни линейкой.
- Тёплая тень как у кожи.

### Для DM

- Тйл песка: вариация только в центре (карточка Tiles). Dither только пятном, не шахматом на весь тайл.

## gems

- URL: https://saint11.art/img/pixel-tutorials/gems.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#gems
- Когда: самоцвет, кабошон, инкрустация.

### Steps

- Стадии: rough → preshape → cut. Стили: brilliant / cushion / cabochon.
- Рисовать: скетч → разметить грани → снять линии → база света → рефракция. Грани чуть случайные; шум не копить.
- Блик по возможности **на всю грань сразу**. В середине анимации блик шире. На гладком (кабошон) — округлые пятна, тот же easing.
- Анатомия: table / crown / girdle / pavilion.
- Рамп: point highlight → reflection → mid → shadow → **shadow refraction** (чуть светлее и насыщеннее в тени) → deep shadow.

### Don'ts

- Блик-лесенка по половине грани.
- Россыпь белых сирот «для блеска».

### Для DM

- 1–2 грани + 1px specular на `fx`. На 64 камень в рукояти — table + одна тень + refraction, не 12 фасетов.

## Tech

- URL: https://saint11.art/img/pixel-tutorials/Tech.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Tech
- Когда: машина, панель, странный механизм.

### Steps

- Панели со швами и винтами; **повторяющиеся** рёбра/венты.
- Chipset: только прямые углы. Кабели снизу — органические, сегментированные.
- Антенны вертикальные; жёлтые полосы опасности; много мелких экранов.
- Анимация: движущиеся части; пар/капли; кабели дрожат, пыль падает (action/reaction); secondary; anticipation + overshoot у панелей; редкий glitch.

### Don'ts

- Один серый blob без швов.
- Кабели как идеальные дуги Безье без сегментов.

### Для DM

- Швы 1px тёмного тона, не чёрный контур каждой панели. Экраны и искры на `fx`. Motion `redraw` для поршней.

## Shine

- URL: https://saint11.art/img/pixel-tutorials/Shine.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Shine
- Когда: блик по металлу, UI-бар, клинок (анимация, не материал).

### Steps

- **Simple:** диагональная полоска 1px едет по форме.
- **Extra:** та же полоска + более широкая вспышка (иногда почти вся поверхность). Simple достаточно часто.
- Работает на круге (блик по ободу) и клинке (полоса вдоль лезвия).

### Don'ts

- Неподвижный белый пиксель вместо едущего блика, если нужна «полировка».

### Для DM

- Shine на `fx`, 2–4 кадра. Не путать с рампой Metal (это движение блика, не затенение).

## skull

- URL: https://saint11.art/img/pixel-tutorials/skull.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#skull
- Когда: скелет, куча костей, микро-череп.

### Steps

- Поворот черепа сложный: показать **скулу (zygomatic) и верхнюю челюсть (maxilla)**.
- При нехватке пикселей порядок: **глазницы → maxilla → скула → зубы → нос → нижняя челюсть → височная ямка**.
- Микро: даже ширина / нечётная ширина; в первую очередь глаза и нос.
- Кости: диагональ экономит пиксели; простая кость = **лента**, не коробка. 1px «мухи» вокруг undead.
- Куча: силуэты черепов → детали → акцент на глазах → край кучи ярче и подробнее; шум и нерегулярность.
- Анимация undead: суставы **лагают** за торсом.

### Don'ts

- Рисовать все зубы на 64 в ущерб глазнице.
- Куча как регулярная сетка костей.

### Для DM

- Совпадает с инвентарём скелета в PIXEL_CRAFT (глазница, скула, 2–3 зуба). Мухи на `fx`. Walk скелета: конечности +1 кадр лага.
