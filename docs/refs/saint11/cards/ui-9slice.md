# UI 9-slice (пачка F) — не дефолт персонажа

Адаптация saint11, CC BY 4.0. Не рисовать 9-slice как персонажа. На галерее два UI-GIF с одним `id=UI`; здесь разобран 9-slice.

## UI

- URL: https://saint11.art/img/pixel-tutorials/UI-9-Slice.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#UI
- Когда: рамка, HP-бар, слайдер — не спрайт существа.

### Steps

- Прямоугольник из 9 кусков: 4 угла, 4 края, середина.
- Края тайлятся сами к себе и к углам. Середина и края **почти без детали**; углы могут быть богаче.
- Растягивать край только у очень простой рамки; иначе tile.
- В коде можно рандомить край/середину; рамку можно анимировать.
- Полоски/виалы — **3-slice** (вертикаль или горизонталь).

### Don'ts

- Уникальный орнамент на каждом тайле края (поедет при масштабе).
- 9-slice на персонаже 64.

### Для DM

- Не слой `line` существа. Если нужен UI в Aseprite — отдельный спрайт, не `create_creature`.
