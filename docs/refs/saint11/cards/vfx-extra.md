## Blood

- URL: https://saint11.art/img/pixel-tutorials/Blood.GIF
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Blood
- Когда: hit-кровь, порез (если заказ допускает gore).

### Steps

- Круглые формы. Капель не переигрывать.
- Крупный splash: острый силуэт → расползти, **держа частицы связанными** как можно дольше.
- Струя: острые края → воздух загибает → гравитация, падают до fade. Сирота только на последнем кадре частицы.
- Потроха: трубки и «водяные шары»; hue-вариации; мелкий мокрый блик.

### Don'ts

- Россыпь капель с кадра 1.
- Сироты на каждом кадре «для брызг».

### Для DM

- Кластеры на `fx`, как дым. Только по явному заказу gore.

## Goo

- URL: https://saint11.art/img/pixel-tutorials/Goo.GIF
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Goo
- Когда: слизь, капля с потолка, slime-проп.

### Steps

- Капля: асимметричный старт, широкая → каждый кадр выше и тоньше; густая дольше висит, может bounce.
- Пузырь слизи тяжелее воды: медленно, гладко, дырки, частицы по одной.
- Рамп: reflection / highlight / base / shadow. Жёсткий маленький specular.
- Толстая слизь: мосты и дыры, капает слоями. Сопротивляется распаду на частицы. Без острых углов.

### Don'ts

- Ломать слизь в сироты как дым.
- Прямой 90° угол у массы.

### Для DM

- Motion `redraw`. Squash с сохранением массы (карточка Squash).

## DarkMagic

- URL: https://saint11.art/img/pixel-tutorials/DarkMagic.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#DarkMagic
- Когда: проклятие, некромантия, «злой» каст.

### Steps

- Чувства: unnatural / chaotic / mystical / ghostly / morbid.
- Комплементарные цвета, высокий контраст, фиолетовый. Дым жиже связан, гаснет спиралью медленно.
- Свет **снизу**. Молнии неестественного цвета, знаки. Чёрный круг для контраста. Острые формы. Перекрывающиеся циклы. Лица/черепа в эффекте.

### Don'ts

- Святой столб сверху (это LightMagic).
- Дым как обычный chimney вверх.

### Для DM

- Свет снизу только на FX, не ломать дефолт key персонажа. Черепа — карточка skull, не копировать с GIF.

## LightMagic

- URL: https://saint11.art/img/pixel-tutorials/LightMagic.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#LightMagic
- Когда: heal, holy, благословение.

### Steps

- Чувства: order / intelligence / cleanliness / calm / good.
- Холод→тёплый рамп, analogous, ярко и насыщенно. Свет **сверху**.
- Искры мало (иначе шум); могут падать или вверх. Trails: порядок, старт быстро → замедление.
- Округлые/квадратные формы, не шипы. Без дыма. События **последовательно**: rain → impact → symbol. Мало взрывов. Вода/дождь ок.

### Don'ts

- Хаотичный splash как DarkMagic.
- Куча искр-сирот.

### Для DM

- Столб на `fx`, символ 1–2 кадра. Не additive blend в Aseprite без нужды — белый/cyan кластер.

## Glitch

- URL: https://saint11.art/img/pixel-tutorials/Glitch.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Glitch
- Когда: баг, голограмма ломается, digital hurt.

### Steps

- Несколько эффектов, потом смесь.
- Горизонтальные полоски сдвиг влево/вправо — не переигрывать.
- V-sync: вертикальный прыжок, чёрно-белые бары, кадры шума.
- Corruption: квадратные выделения, цифры, глифы, чёрные дыры.
- Scanlines: 1px сдвиг/перекрас; цвет nudge вправо (bleed).
- Импровизация, invert. Это «битые данные».

### Don'ts

- Сдвинуть весь спрайт на 8px — силуэт теряется.
- Glitch на каждом кадре idle.

### Для DM

- `shift_cel` по рядам через `run_lua`, не фильтр. 1–2 кадра в `hurt`/`fx`.

## Bullets

- URL: https://saint11.art/img/pixel-tutorials/Bullets.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Bullets
- Когда: снаряд, выстрел.

### Steps

- Ядро теплее и ярче, край холоднее и темнее.
- Крупнее, чем «реализм» — игрок должен видеть. Опасные — blink (дешёво).
- Быстрые: меньше деталей, вытянуты по движению.
- Muzzle flash и impact-шрапнель обязательны (старт и конец), особенно если пуля не видна.

### Don'ts

- 1px пуля на 64 без flash.
- Детальный вращающийся патрон на сверхзвуке.

### Для DM

- Flash 2 кадра на `fx`. Сама пуля может быть отдельным маленьким спрайтом.

## RocketTrail

- URL: https://saint11.art/img/pixel-tutorials/RocketTrail.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#RocketTrail
- Когда: выхлоп ракеты/корабля.

### Steps

- Яркий кадр как мини-взрыв; **подсветить корпус** на этом кадре.
- Растянутое пламя (высокое тонкое) → массу вернуть к соплу, кусок отбросить назад → шире, короче, темнее → ещё темнее и меньше.
- Варианты: частицы; волна как Fire; искры если есть атмосфера (Explosion/Smoke).
- Если корабль сильно едет — частицы лучше кодом, не запечённым GIF.

### Don'ts

- Статичный оранжевый эллипс за кормой.
- Пламя без подсветки корпуса.

### Для DM

- Как Fire, но вытянуто по вектору. `fx` + один кадр lighten корпуса.

## Holograms-Ghosts

- URL: https://saint11.art/img/pixel-tutorials/Holograms-Ghosts.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Holograms-Ghosts
- Когда: призрак, голограмма.

### Steps

- Холодные цвета; тёплые только малонасыщенные. Один главный hue.
- Частицы: форма, по одной в лупе, темнеют и мельчают, старт быстро → медленнее.
- Без полупрозрачности: акцент на контуре, рот, глаза, нос.
- Wireframe: полигоны «3D-граней» (см. Glitch).
- Плаванье: `y = sin(time)` на весь спрайт. Additive blend если движок умеет.

### Don'ts

- Полная непрозрачная заливка как живое тело.
- Тёплый насыщенный призрак без заказа.

### Для DM

- `shift_cel` по синусу 1px. Контур sel-out холодного тона. Не копировать могильный фон с GIF.

## Impact

- URL: https://saint11.art/img/pixel-tutorials/Impact-export.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Impact
- Когда: удар по цели, camera-feel боя.

### Steps

- Преувеличить: smear, дым, шрапнель, гравитация обломков.
- Фазы: idle → anticipation → очень короткое motion → overshoot → длинный rest.
- Цель должна bounce; shake камеры и цели. Выкинуть кадры между rest и целью + smear.
- Freeze: пауза **один кадр до** удара, короткая, только для очень жирного импакта.

### Don'ts

- Линейный удар без реакции цели.
- Длинный freeze (лаг).

### Для DM

- Связать с AttackSheet / Death. Shake = `shift_cel` 1px на 1 кадр. Не двигать камеру Aseprite — только спрайт.

## Breaking

- URL: https://saint11.art/img/pixel-tutorials/Breaking.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Breaking
- Когда: ваза, камень, техника ломается.

### Steps

- Каждая частица как физика, по одной.
- Idle → impact (сначала первый и последний кадр удара) → быстрая середина → взрыв (flash/smoke) → вторичка медленнее → куски; **хотя бы одна узнаваемая исходная форма** → rest.
- Разный timing: flash миг, пыль длиннее, черепки быстро, лёгкое (лепестки) медленно.
- Форма осколка от материала (не все квадраты).

### Don'ts

- Все куски одинаковые квадраты с одной скоростью.
- Потерять узнаваемый кусок — глаз не за что зацепиться.

### Для DM

- Проп `redraw`. Узнаваемый осколок = кусок исходного силуэта, не новый шум.
