# Side-on движение (пачка B)

Адаптация saint11, CC BY 4.0. Источник: [галерея](https://saint11.art/blog/pixel-art-tutorials/). Вид — **side-on**, как дефолт DM.

Дальняя конечность темнее (на гайдах — тёмно-синяя). В DM: `sk_arm_b` / `sk_leg_b` короче и темнее.

---

## Walk

- URL: https://saint11.art/img/pixel-tutorials/Walk.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Walk
- Когда: тег `walk`.

### Steps

- 12 кадров = плавно (6 на ногу). 6 кадров = низкое разрешение (3 на ногу). Дефолт DM walk = 8 — ближе к «полезно в low-res», ключи важнее числа.
- Ключи шага: **contact → down → down+ → prepare passing → passing → up**, потом зеркало ног.
- Contact: передняя нога касается земли.
- Down / down+: корпус и голова вниз, руки максимально в стороны на самом низу.
- Passing: подъём, много вариаций.
- Up: высшая точка.
- Руки **противофазны** ногам. Опорная нога уезжает назад.

### Don'ts

- Обе руки вперёд вместе с той же ногой.
- Ходьба без вертикального bob (1px на 64 достаточно).

### Для DM

- Ключи разложить по 8 кадрам тега: не все 6 имён, а contact / lowest / passing / up + in-betweens.
- `copy_cels` + сдвиг ног; дальняя нога темнее.

## RunCycleSimple

- URL: https://saint11.art/img/pixel-tutorials/RunCycleSimple.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#RunCycleSimple
- Когда: тег `run`.

### Steps

- Цикл из **4 поз**, затем повтор с другой ногой. In-betweens для жидкости (8 или 16 кадров).
- **Jump (в цикле бега):** обе ноги в воздухе, высшая точка, руки против ног.
- **Fall down:** чуть вниз, шире шаг.
- **Contact:** удар о землю, передняя нога прямая, низшая точка.
- **Recover:** готовность скрестить конечности, профиль самый узкий; передняя нога назад, задняя вперёд.

### Don'ts

- Бег как ускоренная ходьба без фазы «обе ноги в воздухе».

### Для DM

- Дефолт run 8 кадров = 4 ключа × 2 ноги. Вертикальный bob больше, чем у walk.

## Jump

- URL: https://saint11.art/img/pixel-tutorials/Jump.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Jump
- Когда: теги `jump` / `fall`.

### Steps

- Если vx = 0 — прыжок **вверх**; если vx > 0 — **вперёд** (наклон корпуса). Пыль/частицы.
- Фазы: anticipation (для игрока часто **укоротить**, иначе лаг) → going up (не луп) → **invert** на пике (мост up→fall; руки контрастные, чтобы следить) → fall (руки вверх, голова вниз, волосы/ткань против скорости) → contact (squash, можно длинный, прерывается).

### Don'ts

- Длинный crouch перед прыжком игрока.
- Fall без invert-кадра на вершине.

### Для DM

- Дефолт jump 3 / fall 3: up, invert, fall+contact. Ткань на `fx`.

## characterIdle

- URL: https://saint11.art/img/pixel-tutorials/characterIdle.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#characterIdle
- Когда: тег `idle`.

### Steps

- База **2 кадра:** вниз 1px (колени, руки чуть в стороны) → вверх 1px (руки вниз). Масса не меняется.
- Средний кадр (3-кадровый idle): замедляет падение, сглаживает колени; **лицо едет с задержкой** относительно силуэта.
- Больше кадров: вторичка (волосы/плащ отстают). Движения **< 1px** — см. карточку Subpixel (пачка H).
- Сначала едет силуэт, **потом** содержимое лица/торса.
- Чисто вертикальный bob скучный: чуть компенсировать **горизонталью**.
- Личность: blink / yawn / look around / scratch — редкие вставки, не каждый цикл.

### Don'ts

- Только вертикаль без рук/плеч.
- Менять объём тела между кадрами (squash «дышащего» мешка без нужды).

### Для DM

- Дефолт idle 4×200ms: down, mid, up, mid. `shift_cel` на 1px + `copy_cels`. Плащ/волосы на `fx` с лагом 1 кадр.

## Slide

- URL: https://saint11.art/img/pixel-tutorials/Slide-Roll.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Slide
- Когда: кастом `add_action("slide"|"roll"|"dash", …)` (не дефолтный тег).

### Steps

- **Roll:** руки на землю → клубок и крутить (чинить шум, вариации кадров) → **overshoot** в низкой посадке → recover в idle. Опциональный кадр «в воздухе перед касанием» даёт характер.
- **Dash/lunge:** 2–3 кадра лупа ветра в полёте; squash-stretch по горизонтали для щелчка; overshoot recover как у roll.
- **Slide:** 1 кадр prepare → короткий луп у земли → 2 кадра recover. Пыль и smear помогают скорости.

### Don'ts

- Идеально одинаковое вращение кадра в roll (выглядит роботом).
- Recover без просадки ниже idle.

### Для DM

- Пыль/smear на `fx`. Не вращать мелкий спрайт целиком (`Modular`: на 64 чаще перерисовать). `redraw` по кадрам.

## WallSlide

- URL: https://saint11.art/img/pixel-tutorials/WallSlide.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#WallSlide
- Когда: кастом wall-slide / wall-kick (платформер).

### Steps

- Контакт со стеной: squash по X, **компенсация растяжением по Y**.
- Скольжение: мелкий shake (ветер); шарф/волосы показывают направление (вниз по стене → ткань вверх). Универсальная поза: одна рука и колено в стену, вторая нога свободна.
- Kick-off: пыль в точке отталкивания; корпус максимально вперёд. Для **игрока** без длинного anticipation (как jump).
- Состояния: jump → fall → wall_contact → slide **или** kick_jump.

### Don'ts

- Скольжение без ткани/волос и без 1px дрожи — «прилип к стене».
- Длинный crouch перед wall-jump игрока.

### Для DM

- Пыль на `fx`. Ткань как у jump. Кастомный тег, не ломать дефолтный `jump`/`fall`.

## Wings

- URL: https://saint11.art/img/pixel-tutorials/Wings.gif
- Страница: https://saint11.art/blog/pixel-art-tutorials/#Wings
- Когда: крылатое существо, hover, насекомое.

### Steps

- Крыло **против фазы** тела. Вверх быстрее, чем вниз.
- Fall: ~1px вниз/кадр, крылья подняты (сопротивление).
- Flap: резкий подъём (~3px), крылья вниз почти смыкаются; затем +1px медленнее.
- Recover: −1px и стоп, крылья в раскрытую позу.
- Hover птицы: вертикаль + subpixel.
- Быстрые крылья: 2–3 кадра, **несколько крыльев в одном кадре** (smear).
- Большие крылья = руки (плечо / локоть / пальцы-рёбра).

### Don'ts

- Симметричный тайминг вверх = вниз.
- Тело на фиксированном Y.
- Крыло и корпус в одну сторону одновременно.

### Для DM

- `shift_cel` по Y асимметрично. Smear насекомых на `fx`. Крупные крылья — `sk_arm_*` или отдельные кости, не один rect.
