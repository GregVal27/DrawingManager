# Pixelblog 17 + 49 — анатомия (принципы)

- 17: https://www.slynyrd.com/blog/2019/5/21/pixelblog-17-human-anatomy
- 49: https://www.slynyrd.com/blog/2024/3/25/pixelblog-49-realistic-human-anatomy
- Когда: гуманоид side-on, сверка пропорций. **Не копировать модели автора.**

Пересказ:

- Жест → wireframe → массы → краска. На мелком спрайте wireframe всё равно спасает пропорции.
- Учебный «идеал» часто 8 голов; для **игры** чаще короче. В DM side-on гуманоид: **~2–2.5 головы** на 64–96, если бриф не просит иное.
- Dummy с цветными сегментами (как наши `vol_*`) проверяет локти/запястья относительно торса до одежды.
- Крупнее холст → экспоненциально дороже каждый кадр и каждая складка. Не класть косметику, которую нельзя протащить через walk.

Демон (не человек): digitigrade, горб — **отдельный объём**, не вздутый человеческий трапециевидный. Те же принципы: жест, сегменты, оклюзия.
