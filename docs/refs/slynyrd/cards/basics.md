# Pixelblog 5 — основы

- URL: https://www.slynyrd.com/blog/2018/5/16/pixelblog-5-back-to-basics
- Когда: новый спрайт, выбор инструмента, масштаб.

Пересказ:

- Пиксель любит **целый масштаб** (×2, ×3…), не дробный ресайз готового арта.
- Рабочий размер выбирают так, чтобы жест читался; слишком мелкий убивает движение, слишком крупный взрывает трудоёмкость каждого кадра.
- Aseprite удобен таймлайном (у нас live + теги). Не рисовать «как в фотошопе фильтром».
- Ограничения (палитра, 1px) — не враг: они заставляют решать форму кластером.

## Для DM

- Не масштабировать готовый персонаж — перерисовать (saint11 Resizing + эта идея).
- 96×96 — комфортный side-on: есть место рампам, ещё не 3D-тексель.
