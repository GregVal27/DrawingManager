# Pixelblog 53 — punches / kicks

- URL: https://www.slynyrd.com/blog/2024/11/25/pixelblog-53-punches-and-kicks
- Когда: кастом ударов, развитие Pixelblog 9. Не копировать dummy-ассеты.

Пересказ:

- Удары вытекают из **idle fighting stance**, не из T-pose.
- Стиль фильтруют под геймплей (коротко, читаемо), даже если анатомия с натуры.
- Кик/кросс: корпус и бёдра участвуют; front kick ≠ round kick по дуге и точке контакта.

## Для DM

- Stance → smear (опц.) → impact hold → overshoot. Hurt extreme — отдельный перерисованный кадр.
- Подробные punches — на следующем персонаже с melee, не на закрытом пробнике.
