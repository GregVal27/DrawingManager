# Pixelblog 2 — текстура

- URL: https://www.slynyrd.com/blog/2018/2/15/pixelblog-2-texture
- Когда: wear, шкура, камень горба, кирпич, листва. После shade.

Пересказ:

- Текстура без системы = шум. Начинать с **простых повторяемых кластеров**, не с каждой чешуйки/листа.
- **Repetition:** 2–4 формы пятна, разный ритм раскладки.
- **Зоны отдыха:** часть площади без текстуры, иначе всё орёт одинаково. Контраст «есть деталь / нет детали» читается лучше, чем равномерный шум.
- Модульная листва (несколько спрайтов, повтор) — для природы; у персонажа тот же принцип: 2 трещины на горбе, не сетка.

## Для DM

- Кластер текстуры 2–8 px. Не 1px dither по телу.
- Скол/трещина = вырез кластера, не контур-решётка.
- Pass 2 шаг Wear после shade.
