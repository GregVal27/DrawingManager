# Pixelblog 10 — вода

- URL: https://www.slynyrd.com/blog/2018/10/12/pixelblog-10-water-in-motion
- Когда: проп `water`, локация shore, водопад. Стык с saint11 Fire/Water.

Пересказ:

- Водопад удобно резать на **рот / поток / всплеск**; блик у кромки падения, поток — ленты, которые темнеют и рвутся вниз; сплэш лупится в ту же фазу.
- Поверхность: простой линейный сдвиг бликов, согласованный с небом/облаками.
- Не рисовать каждую волну уникальной — повтор кластеров + сдвиг фазы.

## Для DM

- Проп: `motion=redraw` или короткий `shift` 1–2px, не персонажный copy+shift.
- Слои `color` / `fx`. Не копировать кадры из поста.
