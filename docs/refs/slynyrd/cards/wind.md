# Pixelblog 33 — ветер

- URL: https://www.slynyrd.com/blog/2021/7/16/pixelblog-33-wind-effects
- Когда: ткань, грива, флаг, листва. Стык с saint11 Fabric.

Пересказ:

- Слои масс качаются **по очереди**, не всем спрайтом.
- Волна: простой путь 1px (вверх-вправо / вниз / назад) со сдвигом фазы между комами листвы.
- Частицы: сначала путь с равным шагом, потом «переворот» вырезом половины пятна.
- Шорох: 4 кадра, лист за листом по ветру.

## Для DM

- Персонаж: грива/хвост перерисовать край, не blit still.
- Проп флаг/трава: `shift` 1px или `redraw` слайдов.
- Не штриховать шерсть.
