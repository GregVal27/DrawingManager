## Pinterest (ограничение сессии)

Встроенный браузер Cursor — **incognito**. Pinterest и Google-вход отвечают: *«You are currently in an incognito/private window»* / *«This browser or app may not be secure»*. Авторизация аккаунтом Google из этого webview **не проходит**.

Что сделано вместо входа:

- Поиск картинок Google по `pixel art walk cycle side view animation` (стрипы, не файлы в репо).
- Живая страница [Pixnote — Animation](https://pixnote.net/en/learn/animation/) (FPS lab, idle/walk/attack).
- Публичные гайды (пересказ, не копировать демо-спрайты).

Если нужно именно **ваши доски Pinterest**: откройте Chrome вне Cursor, **Take Control** на вкладке, войдите вручную — тогда можно продолжить разбор пинов в следующем чате. Канон тот же: смотреть оси, не копировать пиксели.

Типичные пины по этому запросу (то же, что висит на Pinterest): SLYNYRD Pixelblog 50/25/8, горизонтальные sprite sheets, «pogo»-ошибки новичков, side-on 4–8 кадров.
