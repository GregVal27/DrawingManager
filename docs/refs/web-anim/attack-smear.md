# Attack / smear в галереях

Источники: Pixnote attack; sprite-ai.art windup/strike/recovery; saint11 AttackSheet; SLYNYRD 9.

- Структура: **замах (длиннее)** → **удар 1–2 кадра** → **recover**.
- Impact **держать** (дольше мс), in-between быстрее.
- Smear = **одна** дуга цвета по пути оружия/когтя, не промежуточная конечность.
- Для игрока без длинного crouch (лаг).

## Для DM

Smear на `fx`. Гибрид: сдвиг руки/корпуса + кисть + дуга. Не `shift_cel` всего персонажа.
