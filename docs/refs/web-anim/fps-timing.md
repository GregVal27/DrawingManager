# FPS и тайминг

Источники (пересказ): [Pixnote Animation](https://pixnote.net/en/learn/animation/), практика DM-тегов.

| ощущение (Pixnote lab) | FPS | у нас |
| --- | --- | --- |
| слайдшоу | ~2 | не сдавать цикл |
| спокойный idle | ~5–6 | idle **200ms** × 4 ≈ 5 FPS |
| прогулка | ~8–12 | walk **100ms** × 8 |
| бег / удар | ~10–12 | run 80ms, attack 90ms; impact **держать** дольше |

Для пикселя естественен **step** (кадр-щелчок), не плавный lerp. Easing = **разное расстояние между силуэтами** и разный `duration_ms`, не равный `shift` +2,+2,+2.

GIF в сети часто ~10 FPS — не копировать длительность слепо; сверять с тегом в sidecar.
