## Lospec (публично, без Google)

Туториалы walk: [lospec.com/pixel-art-tutorials/tags/walkcycle](https://lospec.com/pixel-art-tutorials/tags/walkcycle) — Pedro Medeiros (walk + quadruped/trot), Dual Core 4/6/8 кадров, Jason Perry side-on 8 кадров.

Примеры циклов в галерее (смотреть, не копировать):

- [Walking Man, 8 frames](https://lospec.com/gallery/kllrbklld/walking-man-animation) — 8 кадров, 13 цветов.
- [Exoskeleton walk, 32²](https://lospec.com/gallery/kennedyrichard/exoskeleton-walk-cycle) — короткий цикл, мало цветов.
- Skeleton / creature walks — поиск `walk cycle` в [Lospec Gallery](https://lospec.com/gallery).

Что снимать с галереи: bob contact/passing, щель между ног, оклюзия, палитра 11–40 цветов на крупном vs ~16–28 на нашем 96.
