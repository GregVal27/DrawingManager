# Как читать галерею (Pinterest / Google Images / стрип)

Когда: любой референс в сети. **Не** импорт в `work/`.

Смотреть **на нативе** (или стрип кадров), отвечая на оси — как [`sideon.md`](../sideon.md):

1. **Силуэт.** На чёрном тесте роль читается на каждом кадре? Щель между ног на contact?
2. **Посадка.** Подошва на одной линии Y? «Плавающие» ноги = нет веса.
3. **Bob.** Contact ниже, passing выше (~1px на 64, 1–2 на 96). Равный прыжок каждый кадр = pogo.
4. **Противофаза.** Руки против ног. Обе руки вперёд с той же ногой — робот.
5. **Оклюзия.** Дальняя нога короче и темнее, не зеркало 1:1.
6. **Вторичка.** Волосы/плащ/хвост **лагают** 1 кадр от торса.
7. **Масса.** Ширина торса почти постоянна (onion). Раздувание = inconsistent volume.
8. **Smear.** На быстрой дуге — пятно цвета, не «нога посередине».

Записать в sidecar тега 1–2 наблюдения («contact низкий, passing +1px, хвост лаг»). Рисовать гибридом: copy still → `shift_rect` частей → кисть.
