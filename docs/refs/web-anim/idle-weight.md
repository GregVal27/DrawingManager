# Idle — вес, не моргание

Источники: Pixnote idle; sprite-ai.art idle (идея 1px дыхания). Поломка: idle только как вспышки века/FX, силуэт столбом.

- Игроки не «смотрят» idle — они замечают его **отсутствие**.
- 2–4 кадра. Движется **горло/грудь/горб** 1–2px, волосы/хвост **против** фазы тела, веко — вторичка.
- Подошвы стоят. Если едет весь спрайт — limb-slide.
- Длинный hold (у нас 200ms), не 80ms как у бега.

## Для DM

Силуэт **обязан** качаться. Гибрид: `shift_rect` корпуса выше копыт, `rotate_pixels` рогов/хвоста мало, кисть шеи. Карточка: [`hybrid-anim.md`](../craft/hybrid-anim.md).
