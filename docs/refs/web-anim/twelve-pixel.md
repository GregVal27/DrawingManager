# 12 принципов → пиксель

Источник: [Pixnote — 12 principles](https://pixnote.net/en/learn/animation/) + Williams (идеи, не цитаты книги).

| принцип | на 64–128 |
| --- | --- |
| Squash & stretch | 1px сжатие посадки / растяжение прыжка; металл почти не squash |
| Anticipation | кадр против удара/прыжка; у игрока короткий |
| Staging | чёрный тест позы |
| Straight ahead / pose-to-pose | ключи сначала, гибрид in-between |
| Follow through | грива/плащ/хвост +1 кадр |
| Slow in/out | расстояние силуэтов, разный ms |
| Arcs | smear по дуге |
| Secondary | веко, ухо, пыль — не вместо bob корпуса |
| Timing | idle медленнее walk |
| Exaggeration | ключ сильнее in-between |
| Solid drawing | объём не скачет (onion) |
| Appeal | один акцент силуэта |

Не заменять [`ANIM_CRAFT.md`](../../ANIM_CRAFT.md).
